Add process-lifetime loose Skills from user and project roots, with bounded catalog and resource tools, layered enablement settings, and explicit per-input selection through the interactive `$` picker. Skills are discovered from both Evil-specific `.evil-jelly/skills` directories and portable `.agents/skills` directories under the user home and workspace roots, with canonical-path deduplication and home-workspace scope protection.

Selected Skills are stored as atomic prompt tokens with dedicated display and submission forms, while logical-column cursor movement keeps multiline editing predictable. Skill and file pickers can now be triggered from any input line, and Skill rows use a compact name, type, and description layout that adds the source only when duplicate names need disambiguation.
