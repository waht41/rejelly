# @rejelly/adapter-langchain

> Convert LangChain tools to Rejelly `ToolDefinition` for [@rejelly/core](https://www.npmjs.com/package/@rejelly/core).

## Install

```bash
npm install @rejelly/core @rejelly/adapter-langchain
```

## Documentation

LangChain adapter: **https://docs.rejelly.dev/en/api/adapter/langchain**
