# @rejelly/adapter-mcp

> Model Context Protocol (MCP) adapter for [@rejelly/core](https://www.npmjs.com/package/@rejelly/core): connect MCP servers, discover tools and resources.

## Install

```bash
npm install @rejelly/core @rejelly/adapter-mcp
```

## Documentation

MCP adapter: **https://docs.rejelly.dev/en/api/adapter/mcp**
