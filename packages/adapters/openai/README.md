# @rejelly/adapter-openai

> OpenAI-compatible ModelAdapter for [@rejelly/core](https://www.npmjs.com/package/@rejelly/core): streaming, tool calling, structured outputs, multimodal.

## Install

```bash
npm install @rejelly/core @rejelly/adapter-openai
```
